# 科技资源管理系统 V4.3 — POC完整核对版

这是一套可直接部署运行的 Web 系统，不是静态 HTML，也不是单页效果图。前端操作通过 REST API 调用 FastAPI 后端，业务数据持久化到 SQLite；附件写入 `uploads/`，审批、预算、TAPD、项目、合同、结算、指标等操作写入审计日志。

## 系统范围

左侧菜单中出现的功能均有实际页面、按钮、后端 API 和持久化逻辑：

- 首页：跨模块驾驶舱、近期需求、在管项目、待审批、快捷入口、平台汇总导出。
- 项目360视图–机器人：项目基本信息、任务、里程碑、预算、需求、合同、结算、业务价值聚合；项目事实问答。
- 业务价值总览：价值指标新增、编辑、删除、目标值、实现值、周期、项目关联、达成率。
- 预算管理：预算新增/维护、预算组成、执行率、剩余预算、项目/需求/合同关联、支出/占用/释放/冲销/追加/调减流水。
- 立项申请：完整立项字段、草稿、删除、提交、部门负责人审批、财务评审、分管领导审批、驳回、审批记录、审批通过转项目。
- 需求申请：需求申请、需求查询、费用评估与预算、需求审批、功能点填报、TAPD 同步、AI 智能问答。
- 项目管理：项目台账、项目编辑、任务 CRUD、里程碑 CRUD、项目风险 CRUD、交付物 CRUD、项目详情联动。
- 结算管理：结算申请、结算明细、结算台账、财务审批、业务负责人确认、完成后自动写预算流水。
- 指标库：指标 CRUD、指标数据录入、历史记录、目标达成率与指标看板。
- 合同管理：合同 CRUD、财务会签、业务终审、付款计划新增/编辑/删除、累计金额校验、合同变更及生效。
- 系统管理：OA/TAPD/AI 集成配置、Mock/Live 模式、连通性检查、全量操作审计。

需求全生命周期部分已按用户本次提供的 POC V1.0 逐条核对并补齐：需求申请、多级审批与OA待办、可退回任意前置节点、产品功能点评估、费用分摊、精确预算校验与执行率/预算组成、终审自动TAPD、多系统拆分、3次×30秒持久化重试、30分钟定时回读、Webhook/手动回读、需求/任务/花费完整字段、>30%双角色预警，以及 AI 五类事实问答。详细矩阵见 `POC_COMPLIANCE.md`。

## PyCharm / macOS 启动

打开 PyCharm，选择本项目整个文件夹，然后在底部 Terminal 执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

浏览器访问：

- 系统：`http://127.0.0.1:8000`
- Swagger API：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/api/health`

以后只要 `.venv` 已存在：

```bash
source .venv/bin/activate
python -m uvicorn app.main:app --reload
```

## Docker 部署

```bash
docker compose up -d --build
```

数据和附件通过 `./data`、`./uploads` 持久化。

## 角色与权限

右上角用户菜单可切换内置业务账号，用于验证 RBAC 和审批节点：需求申请人、部门负责人、产品经理、财务人员、分管总、业务负责人、项目经理、系统管理员。前端请求头使用 ASCII 账号标识，避免 Safari 对中文 HTTP Header 的兼容问题，页面仍显示中文姓名和角色。

## 外部系统集成

`系统管理 → 集成配置` 包含 OA、TAPD、AI 三类适配器：

- `mock`：系统内置适配器实际执行本地业务链路、状态变化、错误码、重试记录和审计，适合 POC/离线验证。
- `live`：用于部署时配置真实服务地址。没有真实第三方凭据时，不会伪造生产系统连接成功。

## 数据重置

默认数据库：`data/trm_system.db`；附件目录：`uploads/`。如需完全重置：

```bash
rm -f data/trm_system.db
python -m uvicorn app.main:app --reload
```
